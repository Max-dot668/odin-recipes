# Odin Recipes

This is my very first project for **The Odin Project** Full Stack JavaScript course!

It is a recipe website built using HTML and CSS. The goal of this project is to practice foundational web development skills, layout structuring, and styling web pages to look clean and visually appealing.

## What I Learned / Skills Demonstrated

Building this project with both HTML and CSS helped me practice:

- Setting up a local project directory and connecting it to GitHub using Git.
- Writing basic HTML boilerplate structure (`<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`).
- Using headings (`<h1>`, `<h2>`, `<h3>`), paragraphs (`<p>`), and text elements.
- Creating lists using unordered lists (`<ul>`) and ordered lists (`<ol>`).
- Adding and styling images (`<img>`) with fixed dimensions and centering containers (`.img-container`).
- Linking multiple pages together using anchor tags (`<a>`) and relative file paths.
- **Styling with CSS:**
  - Applying element, class (`.recipes-list`, `.description`), and global selectors.
  - Customizing typography (font families, sizes, weights, and text alignment).
  - Managing spacing using margins and padding.
  - Customizing link and list appearances (removing default list styles and text decorations).
  - Setting background colors (`floralwhite`).
