# Odin Recipes

This is my very first project for **The Odin Project** Full Stack JavaScript course!

It is a basic recipe website built using only HTML. The goal of this project is to practice foundational web development skills and understand how different web pages connect to each other.

## What I Learned / Skills Demonstrated

Even though this website is simple and unstyled, building it helped me practice:

- Setting up a local project directory and connecting it to GitHub using Git.
- Writing basic HTML boilerplate structure (`<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`).
- Using headings (`<h1>`, `<h2>`), paragraphs (`<p>`), and text elements.
- Creating lists using unordered lists (`<ul>`) and ordered lists (`<ol>`).
- Adding images to a web page (`<img>`).
- Linking multiple pages together using anchor tags (`<a>`) and relative file paths.
